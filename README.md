# Ndeleng TV - Cloudstream Curated Repository

Repository Cloudstream khusus Film Indonesia, Mancanegara 4K/HD, dan Siaran TV Digital Tanpa Konten Anime & NSFW.

## Cara Pasang di Cloudstream:

1. Buka aplikasi **Cloudstream**.
2. Masuk ke **Pengaturan (Settings)** > **Ekstensi (Extensions)** > **Repositori (Repositories)**.
3. Klik **Tambah Repositori (Add Repository)**.
4. Masukkan URL berikut:
```text
https://raw.githubusercontent.com/paranparanjare-bot/ndeleng/main/repo.json
```
5. Simpan, lalu buka tab **Download Extensions** dan pilih provider yang diinginkan.
